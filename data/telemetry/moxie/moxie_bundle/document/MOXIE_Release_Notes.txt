This document, MOXIE_Release_Notes.txt, contains release notes and errata
concerning the Mars 2020 MOXIE archives. It is updated with each release of
MOXIE data.

Section A of this document contains an entry for each MOXIE release with
general information about the contents of the release, in order from newest
to oldest.  Updates to previously released files are reported in these
entries, along with any known errata.

Section B of this file contains general notes, if any, concerning the archive
as a whole.

Release 8 is a complete reprocessing of all MOXIE data files (sols 4 - 901) using the 
latest EDRs provided by JPL IDSO and the updated calibration equations defined in the SIS.  
One change to the reduced and derived data products should be noted:
1. The P_TOT_W column is now computed correctly as the sum of MOXIE Main and SOXE power
   consumption (P_MAIN_W + P_SOXE_W). In previous bundles total power included a value 
   for the compressor power, but this was already included in the Main Power value.
   

   
Release 6 is a complete reprocessing of all MOXIE data files (sols 4 - 631) using the 
updated EDRs provided by JPL IDSO and the updated calibration equations defined in SIS.  
Two changes to the calibrated data products should be noted:
1. The calibrate data products now include columns for pressure calibrated with EICD, Rev H 
   equations (P1, P2, P3, P4, P5) and temperature-corrected pressure (P1_cal, P2_cal, P3_cal, 
   P4_cal, P5_cal). Please updated any analysis tools to use the appropriate columns.
   
2. The calibrated data products include columns for the oxygen partial pressure (in microbar) 
   measured by the anode oxygen sensor (CS4_MBAR) and a temperature-corrected oxygen 
   partial pressure (in millibar) (CS4_MBAR_cal). Please updated any analysis tools to use
   the appropriate columns.
   


Release 5 is a complete reprocessing of all MOXIE data files (sols 4 - 535) using the updated EDRs
provided by JPL IDSO. All data products are now represented in scientific notation
with 4 decimal places precision. For clarity in interpreting the calibrated data
in the RDR files, the column headers for pressures have been changed from P1, P2,
P3, P4, and P5 to P1_cal, P2_cal, P3_cal, P4_cal, and P5_cal. Similarly, the column
header for composition sensor 4 O2 sensor pressure has changed from CS4_MBAR to CS4_MBAR_cal.

Release 3 consists of updates to the calibrated and derived data in both Release 1 and Release 2,
to include revised calibrations and corrections to errata.
